# 와일드리프트 내전 도우미 봇

## 실행 (Python 3.10 이상)
1. `pip install -r requirements.txt`
2. `.env.example`을 `.env`로 복사하고 `DISCORD_TOKEN` 입력 (테스트 서버 ID를 `GUILD_ID`에 넣으면 명령어가 바로 반영됨)
3. `python bot.py`

## 명령어
| 명령어 | 설명 |
|---|---|
| /도움말 | 사용법과 명령어 목록 |
| /티어등록 | 티어, 단계, 주/부 라인 등록 (다시 하면 덮어씀) |
| /정보수정 | 바뀐 항목만 골라서 수정 (부 라인은 '없음'으로 삭제 가능) |
| /내정보 | 티어, 내전 전적, 전력 점수 |
| /내전모집 | 10명 모집 (참가/취소/라인 변경) → 방장이 팀 짜기. 같은 주 라인이 이미 2명이면 참가 전에 재확인 |
| /게임끝 | 이름 버튼으로 누구나 KDA 입력, 승리 팀 선택, 방장이 결과 확정 |
| /랭킹 | 전력 점수 TOP 10 |
| /챔피언추천 | 재미용 랜덤 챔피언 (와일드리프트 챔피언만) |

## 전력 점수
티어 30% + 내전 성적(승률 50% + KDA 50%) 70%. 판수가 적으면 티어 점수 쪽으로 보정 (`scoring.py`).
팀 추천 가중치는 `balance.py` 상단 상수에서 조절.

## 챔피언 목록 (champions.json)
- 와일드리프트 142명 기준 (패치 7.3c, 2026-10-26 작성). 라인 분류는 재미용이라 자유롭게 수정해도 돼요.
- 신규 챔피언이 나오면 아래 형식으로 한 줄 추가하면 바로 추천 대상에 들어가요 (봇 재시작 불필요).
```json
{"ko": "한글이름", "en": "EnglishName", "lanes": ["미드", "서폿"]}
```
